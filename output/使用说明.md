# 机房监控系统 · 小机房

双击 `机房监控系统-小机房.html` 即可离线打开，无需安装依赖。建议使用桌面 Chrome 或 Edge。

## 修改源码

编辑 `index.html`（结构、展示数据）、`styles.css`（样式、响应式布局）和 `app.js`（交互）。浏览器打开并刷新 `index.html` 可查看修改，保留 `assets/` 素材目录。

修改后运行 `python scripts/build.py`，同步生成独立 HTML 和 `small-room-source.zip`。Python 脚本仅使用标准库。

## 自适应布局

页面直接填满浏览器的可见宽高，不再对整页等比缩放。顶部栏高 74px、左侧导航宽 152px、二级按钮 140×48px、三级按钮 117×38px，均保持固定尺寸。导航溢出时在自身区域滚动，左侧导航支持垂直滚动；收起导航后宽 64px，右侧工作区自动扩展。

桌面布局中，两侧面板列各宽 400px，中间区域使用剩余宽度。每列三个面板均分浏览器剩余高度，标题、图标、文字保持原尺寸，内容不足以显示时出现真正可操作的滚动条。PUE、UPS 概况、环境状态、平均温湿度、空调概览和告警级别统计均支持独立滚动。

实时告警使用原生滚动容器，蓝色滚动条可拖动，支持滚轮、触控板和键盘；表头固定，表格列较宽时可在表格内水平滚动。没有使用装饰矩形模拟滚动条。

窄于 1100px 时面板重排；极窄窗口中面板限制在工作区宽度以内，避免整个页面横向溢出。导航本身保留固定尺寸，机房场景和设备标签一起缩放适应中间区域。

## 演示功能和数据

设备标签查看详情、点击“未确认”确认告警、告警列表滚动、导航收起、主题亮度切换、静音切换、北京时间时钟、全屏。数据为设计示例，告警确认仅作用于当前页面，刷新后重置；尚未连接后台和真实设备。其他机房与模块显示暂无数据提示。

素材来自用户提供的 Figma 文件，使用独立素材图层导出版本，部分装饰细节与源稿可能略有不同。
